Features

One job, done carefully.

Everything below is in the app today, running entirely on your Mac.

Reads only likely candidates

Files are grouped by size, then by a hash of their first and last 64 KB, then by a full streaming SHA-256. Hashing runs in parallel with a progress bar and a Cancel button.

Clear keep-one preview

Each group expands to show every copy with its folder, modified date and size. The copy you keep is labelled Keep, and copies marked for removal are dimmed.

Auto-select rules

Keep the oldest, the newest, the shortest path or the copy in the first folder you added. Changing the rule re-applies it right away.

Safe by design

At least one copy in every group always stays unselected, and files go to the Trash after a confirmation that shows the space you will free.

Sensible scan options

Drag in folders or press ⌘O, and set a minimum file size, hidden files and package handling. Symlinks, aliases and empty files are skipped, and hard links count as one file.

Offline and native

Built with SwiftUI and Apple frameworks only, with no network calls, analytics or third-party dependencies.

Install

Up and running in a minute.

TwinFileSweep is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download TwinFileSweep-macOS.zip and unzip it.
  2. Move TwinFileSweep.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/TwinFileSweep.app
  4. If you scan a protected folder such as Desktop, Documents or Downloads, allow the standard macOS prompt, or enable it later in System Settings › Privacy Security › Files and Folders.

FAQ

Questions, answered.

Is TwinFileSweep really free and open source?

Yes. It is released under the MIT license and the full source is on GitHub. If it saved you some disk space, there is an optional Support button that links to Ko-fi.

What permissions does it need?

No Accessibility, Screen Recording, Microphone, Camera or network access. It only reads folders you add by drag and drop or the open panel, and macOS may ask for Files and Folders access for protected locations like Documents.

Where is my data stored?

Nothing leaves your Mac. The app saves only your folder list, minimum size, hidden and package options and keep rule in its local preferences. Trashed files stay recoverable from the Trash.

Why isn't the app notarized?

Notarization needs a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to get past Gatekeeper, or build it yourself from source.

Was this written by AI?

Yes. TwinFileSweep was generated by Claude Code from a written spec as a clean-room reimplementation, with no code or assets from any commercial app. The full source is on GitHub under MIT, so you can read every line before you run it. It has had less human review than a hand-written app, so bug reports are welcome.
